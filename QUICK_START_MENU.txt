🚀 TROIS FAÇONS DE GÉRER LE MENU :
═══════════════════════════════════════════════════════════════════════════

1️⃣ UPLOAD VIA WEB (PLUS FACILE) 🌐
   ➜ Va à : http://localhost:5173/admin/menu-setup
   ➜ Upload un PDF
   ➜ Done ! L'ancien s'écrase automatiquement

2️⃣ RÉGÉNÉRER VIA TERMINAL 💻
   ➜ npm run menu:generate
   ➜ Utilise le contenu du script generate-menu-pdf.js

3️⃣ ÉDITER LE SCRIPT 📝
   ➜ Ouvre : scripts/generate-menu-pdf.js
   ➜ Modifie les arrays (entrees, plats, desserts)
   ➜ Sauvegarde et relance : npm run menu:generate

🎯 FLUX DE TRAVAIL TYPE :
═══════════════════════════════════════════════════════════════════════════

Lundi (création du menu du jour) :
  1. Prépare ton menu du jour (contenu, prix)
  2. Option A : Édite scripts/generate-menu-pdf.js + npm run menu:generate
  3. Option B : Upload un PDF via /admin/menu-setup
  4. Teste sur le site : les boutons affichent le PDF

Vendredi (mise à jour) :
  1. Même processus
  2. L'ancien PDF est automatiquement remplacé ✅


⚙️ PERSONNALISATION :
═══════════════════════════════════════════════════════════════════════════

Modifier le contenu :
  Ouvre : scripts/generate-menu-pdf.js
  Cherche : const entrees = [ ... ]
  Édite  : nom, description, prix
  Exécute: npm run menu:generate

Modifier les couleurs :
  Ouvre : scripts/generate-menu-pdf.js
  Cherche : const colors = { ... }
  Édite  : les valeurs HEX
  Exécutes: npm run menu:generate

Format du PDF :
  • Format    : A4
  • Marges    : 40px
  • Pages     : 1
  • Branding  : Tifinagh (en-tête + footer)
  • Sections  : Entrées | Plats | Desserts

❓ DÉPANNAGE RAPIDE :
═══════════════════════════════════════════════════════════════════════════

404 sur le menu ?
  → npm run menu:generate
  → Vide le cache du navigateur (Cmd+Shift+R)

PDF ne change pas après upload ?
  → Vide le cache (Cmd+Shift+R)
  → Relance le serveur (npm run dev)

Erreur de génération ?
  → Vérifie que pdfkit est installé : npm list pdfkit
  → Réinstalle si besoin : npm install pdfkit

Upload ne marche pas ?
  → Vérif : c'est un PDF ? < 5MB ?
  → Regarde la console du navigateur (F12)


💡 PRO TIPS :
═══════════════════════════════════════════════════════════════════════════

• Save la palette de couleurs que tu aimes dans un commentaire du script
• Crée des versions du script pour différentes saisons (été/hiver)
• Le template (generate-menu-pdf-template.js) peut être chargé depuis JSON/BD
• Pour automatiser : crée une tâche cron qui met à jour le menu chaque jour
