🚀 DÉMARRAGE RAPIDE (2 étapes)

1. Créez un PDF avec votre menu du jour
   → Utilisez Canva, Word, Google Docs, Adobe, etc.
   → Exportez en PDF

2. Uploader le PDF via l'interface admin
   → Allez sur : http://localhost:3000/admin/menu-setup
   → Cliquez sur "📤 Sélectionner un PDF"
   → Choisissez votre fichier
   → Confirmez
   → ✅ C'est live !

──────────────────────────────────────────────────────────────────────────────

  Content-Type: multipart/form-data
  Body: file=@menu.pdf

🚀 DÉPLOIEMENT (Production)

Pour Vercel / Server Node.js / VPS :

1. Créez un dossier `public/` à la racine du projet
2. Uploader votre PDF initial via l'interface admin
3. Ou via FTP : placez `menu-du-jour.pdf` dans le dossier `public/`
4. Redéployez votre site
5. L'interface admin fonctionnera immédiatement


⚙️ CONFIGURATION (Optionnel)

Vous pouvez modifier ces valeurs dans menu-pdf-button.tsx :
- Taille max fichier : 5 * 1024 * 1024 (bytes) → modifiez dans app/api/upload-menu/route.ts
- Accepter d'autres formats : modifiez `accept=".pdf"` dans menu-pdf-button.tsx


🆘 FAQ

Q: Le PDF n'est pas à jour après l'upload ?
A: Essayez un hard refresh (Cmd+Shift+R sur Mac, Ctrl+Shift+R sur Windows)

Q: Impossible d'uploader un fichier PDF ?
A: Vérifiez que c'est bien un PDF et pas > 5 MB

Q: Comment supprimer le PDF existant ?
A: Supprimez le fichier public/menu-du-jour.pdf — un message d'erreur s'affichera

Q: Puis-je automatiser les uploads quotidiens ?
A: Oui ! Utilisez un CRON job + curl pour appeler l'endpoint /api/upload-menu
