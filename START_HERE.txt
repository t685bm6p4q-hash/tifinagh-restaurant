  ❓ QUESTIONS RAPIDES
═══════════════════════════════════════════════════════════════════════════

Q: Comment mettre à jour le menu ?
R: Trois façons (voir ci-dessus) :
   • Upload via /admin/menu-setup (plus facile)
   • npm run menu:generate (CLI)
   • Éditer le script et régénérer (personnalisation)

Q: Le PDF peut-il être téléchargé par les utilisateurs ?
R: Non. Il s'ouvre en consultation uniquement (pas de bouton DL).

Q: Quand j'upload un nouveau PDF, l'ancien s'écrase ?
R: Oui. Automatiquement. C'est conçu pour ça.

Q: Où se trouve le PDF sur le serveur ?
R: public/menu-du-jour.pdf
   Accessible via /menu-du-jour.pdf sur le site

Q: Je peux personnaliser le design du PDF ?
R: Oui. Édite :
   • Contenu (entrées, plats, prix) : arrays dans le script
   • Couleurs : const colors = { ... }
   • Layout : font sizes, spacing, etc.

Q: Comment ajouter une authentification ?
R: Voir DEPLOYMENT_CHECKLIST.md (section sécurité)

Q: Je suis perdu, par où commencer ?
R: Lis QUICK_START_MENU.txt (2 pages, simple)
